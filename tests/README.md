# الاختبارات الآلية

`tests/api/` — اختبارات الخادم (Python بلا مكتبات خارجية) تُشغَّل على خادمين محليين: النسخة السعودية على المنفذ 3100 والمصرية على 3200.

- فحص الترحيل `posting_audit.py`: كل نوع مستند وقيده ومطابقة الدفاتر بعده.
- مطابقة البيانات التجريبية `final_audit.py`.
- عزل المنشآت `r326_iso.py`.
- بقية الملفات: خصائص كل إصدار (الفواتير، المصروفات، المشاريع، المساعد، بيانات العملاء والموردين…).

التشغيل: `bash tests/api/run_all.sh` بعد تشغيل الخادمين. تُشغَّل تلقائياً على GitHub عند كل دفع إلى `main` (`.github/workflows/ci.yml`).
