# ميزان لايت — نسخة الأساسيات لأجهزة أندرويد

نقطة بيع ومحاسبة أساسية من نظام ميزان: تعمل على الجهاز بلا إنترنت وبلا تسجيل دخول، والبيانات محفوظة محلياً.

## المحتوى
- `src/core.js` المحرك المحاسبي (قيد مزدوج، المبالغ بالهللة أعداداً صحيحة، QR الهيئة للمرحلة الأولى، التفقيط).
- `src/ui1.js` `ui2.js` `ui3.js` `print.js` `style.css` الواجهة وقوالب الطباعة.
- `build.js` يجمع كل شيء في ملف واحد `dist/index.html` وينسخه إلى `android/app/src/main/assets/`.
- `android/` مشروع أندرويد (WebView، بلا مكتبات خارجية) — الحد الأدنى أندرويد 5.0.
- `test/engine.test.js` اختبار المحرك (43 فحصاً)، `test/ui_test.py` اختبار الواجهة على أربعة مقاسات (128 فحصاً).
- بناء الـAPK: `.github/workflows/android-lite.yml` في جذر المستودع.

## البناء محلياً
    npm install && npm test && npm run build
    cd android && gradle assembleRelease      # يحتاج Android SDK (compileSdk 34) و JDK 17

## مفتاح التوقيع
- مخزن المفاتيح `android/keystore/mizan-lite.p12` (الاسم المستعار `mizanlite`) محفوظ هنا **مشفَّراً** بكلمة مرور عشوائية طويلة ليست في المستودع.
- كلمة المرور توضع مرة واحدة في سر المستودع `LITE_KEYSTORE_PASSWORD`. بدونها يُبنى الملف بتوقيع تجريبي (`-test`).
- كل تحديث يجب أن يُوقَّع بالمفتاح نفسه ليُثبَّت فوق النسخة السابقة دون فقد البيانات — لا تستبدل الملف ولا تفقد كلمة المرور.

## الربط مع النسخة الأصلية
- التطبيق يقرأ `apps/lite/version.json` من الفرع `main` (الإعدادات ← التحديث) ويعرض رابط تنزيل الإصدار الأحدث.
- لإصدار جديد: ارفع الرقم في `package.json` و`VERSION` داخل `src/core.js` و`version.json` معاً، ثم شغّل «Android Lite» مع release.
- إصدارات لايت بوسم `lite-vX.Y.Z` و`--latest=false` حتى لا يتأثر التحديث التلقائي لنسخة سطح المكتب.

## لم يُتحقق منه بعد
- بناء Gradle والتشغيل على جهاز فعلي (كود Java مفحوص بالمترجم مقابل واجهات أندرويد 34 فقط).
- الطباعة على طابعة حرارية فعلية وعلى طابعات أجهزة الدفع المدمجة (تحتاج خدمة طباعة على الجهاز أو SDK الشركة المصنّعة).
