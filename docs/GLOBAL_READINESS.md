# جاهزية ميزان ERP للمستوى العالمي — فحص الفجوات (الإصدار 3.26.0)

فحص للنظام مقابل ما تقدمه الأنظمة العالمية والمعايير المعتمدة. «موجود» = مختبر آلياً في هذا المستودع. «ناقص» = غير منفَّذ.

## الأمان (OWASP ASVS / Secure Headers)
| البند | الحالة |
|---|---|
| رؤوس الأمان: CSP بلا سكربتات مضمّنة، nosniff، منع التضمين، Referrer-Policy، Permissions-Policy، HSTS على HTTPS | **أضيف في 3.25.0** |
| التحقق بخطوتين TOTP مع رموز استرداد | **أضيف في 3.25.0** |
| شاشة تغيير كلمة المرور وسياسة قوتها | **أضيف في 3.25.0** (كانت الواجهة ناقصة) |
| حماية الحساب التجريبي المشترك من تغيير كلمة مروره | **أضيف في 3.25.0** |
| قفل الدخول بعد 5 محاولات فاشلة، تشفير كلمات المرور (bcrypt)، صلاحيات بالأدوار، سجل تدقيق | موجود |
| عدم تحميل أي مورد من طرف ثالث (الخط مضمَّن) | **أضيف في 3.25.0** |
| security.txt و robots.txt | **أضيف في 3.25.0** |
| الدخول الموحّد SSO (Google / Microsoft / SAML) | ناقص |
| قائمة الجلسات النشطة وإنهاؤها من بُعد، وإبطال الرموز عند تغيير كلمة المرور | ناقص |
| اختبار اختراق خارجي مستقل، وشهادة SOC 2 / ISO 27001 | ناقص (إجراء تنظيمي لا برمجي) |
| تشفير الحقول الحساسة داخل قاعدة البيانات (IBAN، الهويات) | ناقص |

## المحاسبة والضرائب
| البند | الحالة |
|---|---|
| القيد المزدوج، الإقفال، القوائم الأربع، مطابقة الدفاتر المساعدة | موجود ومختبر (فحص الترحيل والمطابقة) |
| ضريبة القيمة المضافة، الاستقطاع، الزكاة، الفاتورة الإلكترونية (توليد وربط) | موجود؛ **الربط الفعلي مع «فاتورة» لم يُختبر ببيانات إنتاج** |
| تعدد العملات مع فروق الصرف، مراكز التكلفة والمشاريع، الأصول والإهلاك، الرواتب | موجود |
| إيضاحات القوائم المالية وفق IFRS for SMEs، والإفصاحات | ناقص |
| توحيد قوائم عدة منشآت (Consolidation) واستبعاد المعاملات البينية | ناقص |
| الإيراد المؤجل والاستحقاقات الآلية (IFRS 15 / IFRS 16 لعقود الإيجار) | ناقص |
| ربط بنكي مباشر (Open Banking / SAMA) لجلب الكشوف آلياً | ناقص (الاستيراد يدوي من ملف) |
| دول أخرى غير السعودية ومصر (الإمارات، الكويت… بضرائبها ودليل حساباتها) | ناقص |
